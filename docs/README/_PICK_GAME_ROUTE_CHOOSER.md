# _pick_game_route_chooser.sh

CDP pick for the game-route chooser when the BrowserView popup is not visible in VR.

## Usage

```
bash test/_pick_game_route_chooser.sh steamvr
bash test/_pick_game_route_chooser.sh tovakai
bash test/_pick_game_route_chooser.sh cancel
```

Requires the patch armed (`_arm_game_route_chooser.sh`) and a pending launch
(after Play on a flat game). See [_ARM_GAME_ROUTE_CHOOSER.md](_ARM_GAME_ROUTE_CHOOSER.md).
