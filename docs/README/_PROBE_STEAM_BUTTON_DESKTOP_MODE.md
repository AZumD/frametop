# _probe_steam_button_desktop_mode.sh

Observe what a physical Steam/System button press does on SharedJS
(`RegisterForSystemKeyEvents`, OpenVR button, dashboard visibility).

## Usage

```
bash test/_probe_steam_button_desktop_mode.sh arm
# press Steam button once
bash test/_probe_steam_button_desktop_mode.sh dump
bash test/_probe_steam_button_desktop_mode.sh dispose
```
