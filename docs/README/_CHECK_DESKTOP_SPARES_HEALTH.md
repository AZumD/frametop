# _check_desktop_spares_health.sh

Thin wrapper: `scripts/revive-desktop.sh --check` (SteamVR, `--spares`, nested desktop health). Prefer [REVIVE-DESKTOP.md](REVIVE-DESKTOP.md).

## Usage

```
bash test/_check_desktop_spares_health.sh
# or:
bash scripts/revive-desktop.sh --check
desktops.sh revive --check
```

If the binary is missing `--spares`, see [_FIX_DESKTOP_SPARES_MISMATCH.md](_FIX_DESKTOP_SPARES_MISMATCH.md).
